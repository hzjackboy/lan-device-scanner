扫描原理

  • ARP 缓存 + UDP 触发 ARP：非 root 拿到真实 MAC，能发现禁 ping 的设备，局域网里最有效的一招。
  • ICMP 并发 ping：拿延迟，同时补上 ARP 表里没有的在线设备。
  • mDNS / Bonjour：解析 _airplay、_googlecast、_ipp、_hap 等服务，拿到设备名。
  • 反向 DNS / NetBIOS：拿主机名，后者是自实现的 NBSTAT 报文，专门捞 Windows 机器名。
  • TCP connect 端口探测：快速档 10 个、完整档 67 个常见端口，用于设备指纹。
  • OUI 厂商库：内置常见厂商 + IEEE 全量表，随机 MAC 会标成"私有/随机 MAC"。

使用提醒

  • 服务默认监听 0.0.0.0，需要登录才能使用；默认账号 admin / admin，首次登录会强制要求改密码。
  • 局域网里走的是明文 HTTP，Cookie 有 HttpOnly + SameSite=Lax，但没有 TLS；跨公网请在前面套 HTTPS 反代。
  • ARP 只在本广播域有效，扫其他子网会退化成 ICMP + 端口探测。
  • 端口扫描是 connect 扫描，会留下完整 TCP 连接记录，只适合在自己网络里用。
  • 只扫描自己有权管理的网络。
